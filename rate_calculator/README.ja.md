# 動画編集 見積もり計算ツール v1

クライアントが動画の条件を入力すると、制作費の見積もりを計算するコマンドラインツール。

## 使い方
```bash
python rate_calculator.py
```

## 料金ルール
| 完成尺 | 基本料金 |
|---|---|
| 30秒以下 | $50 |
| 31〜60秒 | $100 |
| 61〜90秒 | $150 |
| 91〜120秒 | $200 |
| 121秒以上 | Custom quote（別途見積もり） |

- 編集あり：+$100
- カラーあり：+$50
- 小計 = (基本料金 + 追加料金) × 本数

## 処理の流れ
1. 完成尺・編集の有無・カラーの有無・本数を入力
2. 「他にも追加しますか？」でyesなら1に戻る
3. noなら全案件の合計を表示

## 想定外の入力のとき
- 121秒以上：基本料金を0として計算し、合計に「+ Custom quote（件数）」を表示
- yes/no以外の入力：聞き直す

## 学んだこと
- 関数に引数を渡して、1つの関数を使い回す方法
- Noneを返して「普通の値ではない」ことを伝える方法
- ループの外で合計用の変数を用意して積み上げる方法
